# Segnalazioni di sicurezza

Inviare le segnalazioni a **vgiusti@unirc.eu**, il contatto del progetto
riportato anche nell'applicazione. Non pubblicare dettagli sfruttabili nelle
issue prima del confronto con il manutentore.

Indicare versione, sistema operativo, impatto e passaggi riproducibili con
dati sintetici. Non inviare database aziendali, disegni riservati o credenziali.
Non è attualmente garantito un tempo di risposta né un programma di supporto
per versioni precedenti alla prima release pubblica.
